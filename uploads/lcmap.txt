ESQ Curriculum Map
This resource includes:
• Learning components assessed in each Milestone
◦ Note: Standards marked with an asterisk (*) indicate that one or more learning components have a restriction
• Standards, curriculum-specific focus lessons and common misconceptions related to each learning
component
How to Use
1. Locate each learning component that appears on your Prepare for Instruction report.
2. Identify the focus lesson(s) for predicted strengths and predicted challenges.
3. Learn about common misconceptions and strategies in the Instructional Moves modules.
4. Plan instruction for each focus lesson and consider...
a. Continuing with regular instruction for predicted strengths
b. Applying strategies from the Instructional Moves modules to address misconceptions for predicted
challenges
